# pennybot2 — 처음부터 다시 만들기 계획

기존 `pennybot/`(약 3만 줄)은 **그대로 두고**, `v2/` 폴더 안에 새로 만든다. 마음에 들면 갈아타고, 아니면 기존 것을 계속 쓴다.
변경 기록은 `v2/CHANGELOG.md` (루트의 `CHANGELOG.md` 는 기존 버전 것).
`v2/` 안에서 `python -m pytest -q` 로 테스트, 상태 파일은 `v2/state/`.

## 원칙
- 시세는 LS증권 OpenAPI 하나만 (토스 코드 없음). 매매는 모의가 기본, 실거래는 `mode: live` + `PENNYBOT_LIVE_CONFIRM=YES` 둘 다.
- 파일 하나는 400줄 안쪽. 수집기 3천 줄짜리 덩어리 금지 — 기능별로 쪼갠다.
- 파일 입출력은 항상 `encoding="utf-8"`.

## 구조 (2026-11-25 확정)
입력(feeds) → 이벤트 버스 → 감지기(detectors) → 출력(sinks). 부품끼리는 직접 부르지 않고 이벤트만 주고받는다.
부품 하나가 죽어도 나머지는 계속 돈다. 저장된 이벤트를 재생(replay)하면 그대로 백테스트. 프로세스는 `pennybot2 run` 하나.

## 단계 (끝낸 것에 [x])
- [x] 1. 뼈대: 설정, 세션 캘린더, SQLite 저장소, 테스트
- [x] 2. 이벤트·버스, feeds/detectors/sinks 규칙, 재생 입력, 급등 감지기, 콘솔·알림 출력
- [ ] 3. LS 입력: 토큰·웹소켓·REST 로 Tick/Bar 를 내는 feed (`feeds/ls/`)
- [ ] 4. 저장 출력과 일봉 동기화(야후), 전날 밤 점수로 후보 선정 감지기
- [ ] 5. 감지기 추가: 거래 터짐, 공시(SEC 희석), 뉴스. 신호에 등급·차트 모양 붙이기
- [ ] 6. `pennybot2 run` (실시간 한 프로세스, 워치독), 윈도우 스크립트
- [ ] 7. 대시보드(127.0.0.1:8050)와 텔레그램 명령
- [ ] 8. 모의매매 출력(전략·리스크·저널·일일 리포트)

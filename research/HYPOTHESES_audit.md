# 새 가설 (2026-11-15, 감사 연구에서 파생) — 기존 검증(P1·research_early·research_export)과 독립

상태 표기: **미검증**. 아래는 아직 어떤 데이터로도 시험하지 않았고, 시험은 2026-11-16 이후 새 데이터로만 한다. P1 동결 규칙·판정 기준과 섞지 않는다.

## N1 — 신선한 호가 게이트 (체결 가능성 우선)
- 근거: 현재 호가 간격 ~100초라 5~30초 신선한 호가가 있는 사건이 3~6% (감사). 실제 체결가는 봉 가정보다 5~7%p 나쁨.
- 가설: 트리거 순간 호가(≤15초)가 스프레드 ≤2% · 매수1호가 잔량 ≥$1,000 일 때만 진입하면 호가 체결 기준으로도 기대수익 > 0 인 부분집합이 존재한다.
- 필요: 수집기가 트리거 순간 모든 후보의 bid/ask 를 저장 (미구현, 승인 필요). 평가 = 호가 체결 + 계좌 위험 1% + 용량(잔량의 30% 이하).
- 기각 기준: 새 데이터 150건↑ 에서 계좌 손익/거래 ≤ 0 이면 기각.

## N2 — 두 번째 폭발 (re-arm)
- 근거: +30% 도달의 63% 가 120분 이후 (중앙 198분), PMAX 는 538분 뒤 — 첫 트리거와 다른 별개의 폭발일 수 있음.
- 가설: 첫 트리거 뒤 가라앉았다가 같은 날 **두 번째** 거래량 폭발(같은 정의)이 나온 종목은, 두 번째 트리거에서 120분 안 +30% 확률이 첫 트리거보다 높거나 손익이 다르다. 두 번째 트리거만 새 신호로 취급 (첫 번째는 건너뜀).
- 주의: 재가속 알림과 다름 — 같은 트리거 정의를 재사용하는 시험이며, 기존 알림 성과를 검증에 쓰지 않음.
- 평가: 신호당 120분 안 도달 확률 + 호가 체결 손익. 기각 기준: 두 번째 트리거의 신호당 순수익이 첫 트리거(−1.8~−2.7%)와 통계적으로 차이 없으면 기각.

## N3 — 용량 상한 사전 측정 (전략이 아니라 가능 규모 분석)
- 근거: +20% 매수호가 잔량 중앙 $1,794. 
- 가설: 승자의 청산 가능 금액(잔량의 30%)과 수익률을 곱한 '거래당 기대 수익금'이 수수료·누락 비용을 넘을 정도로 큰 상황이 존재하지 않는다 (용량 한계가 수익 한계). 호가 로깅 뒤 사건별 용량 분포를 산출해 N1 의 필수 전제로 사용.

## N4 — 야간 후보 ∧ 실시간 포착 ∧ 신선한 호가의 '알림 정밀도' (매수 아님)
- 근거: 실시간 포착 ∧ 모델 상위 200 의 +30%(하루) 확률 19.75%, +10% 신호 27.5% (탐색).
- 가설: 이 조합 알림의 앞으로의 정밀도(+10% 신호 도달 60분 안, +30% 하루 안)가 탐색 기간 수치의 절반 이상으로 유지된다. 알림 전용 사전 등록, 손익 평가 아님.
- 기각 기준: 새 데이터 100건↑ 에서 +10% 신호 도달률이 평균(6.9%)의 2배 미만이면 기각.

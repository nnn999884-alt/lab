# pennybot — 미국 페니주 자동매매 (토스증권 Open API)

토스증권으로 미국 페니주를 자동매매하는 봇입니다. **수집기(24시간)** 가 시장 데이터를 모으고,
**매매 봇**이 그 데이터로 후보를 찾아 사고팔며, **대시보드**에서 상태를 봅니다. 기본은 **모의매매**입니다.

> ⚠️ 페니주는 변동성·스프레드·거래정지·상장폐지 위험이 매우 큽니다.
> 이 코드는 수익을 보장하지 않으며, 반드시 **모의매매로 충분히 검증한 뒤** 소액으로 시작하세요.

**문서 지도**
- 이 파일: 설치·실행 방법과 **지금 코드가 하는 일**
- [CHANGELOG.md](CHANGELOG.md): **날짜별 변경 기록**. 동작이 바뀌면 여기에 날짜와 함께 남깁니다.
- [CLAUDE.md](CLAUDE.md): 이 PC 에서 작업할 때의 규칙과 실제 토스 연결 검증 순서
- [docs/toss_api.md](docs/toss_api.md): 토스 API 사용법과 제약

## 내 컴퓨터에서 실행하기

처음 한 번만 1~7, 그다음부터는 `start.bat` 더블클릭이면 됩니다.
(맥은 `.bat` 대신 터미널에서 `bash setup.sh`, `./pennybot.sh`, `./start.sh`)

1. **코드 받기 (git 으로, 권장)**: [Git](https://git-scm.com/download/win) 설치 후 명령 프롬프트에서
   ```
   cd C:\
   git clone -b claude/elegant-galileo-1nmavv https://github.com/nnn999884-alt/lab.git pennybot
   ```
   비공개 저장소라 처음에 GitHub 로그인 창이 뜹니다. 이후 새 버전은 **`update.bat` 더블클릭**이면 받아집니다
   (`.env`, `config.yaml`, `state` 폴더는 그대로 유지).
   - git 없이: [브랜치 페이지](https://github.com/nnn999884-alt/lab/tree/claude/elegant-galileo-1nmavv) → **Code** → **Download ZIP**
     → `C:\pennybot` 처럼 경로에 한글·공백 없는 곳에 풀기 (업데이트 때마다 다시 받아야 함)
2. **파이썬 설치**: <https://www.python.org/downloads/> 에서 3.12 설치. 첫 화면의 **Add python.exe to PATH** 체크.
3. **`setup.bat` 더블클릭**: 패키지를 설치하고 `.env`(비밀값 파일)를 메모장으로 엽니다. 아직 키가 없으면 그냥 닫아도 됩니다.
4. **미리보기 (키 없이)**: 폴더 주소창에 `cmd` 입력 후 Enter → `pennybot.bat dashboard --demo`
   → 브라우저로 <http://127.0.0.1:8050> (예시 데이터). 끌 때는 검은 창에서 Ctrl+C.
5. **토스 Open API 키**: 토스증권 **설정 > Open API**에서 발급 ([개발자 문서](https://developers.tossinvest.com/docs)).
   같은 화면 아래 **허용 IP 관리**에 이 컴퓨터의 공인 IP를 등록합니다 (네이버에서 "내 아이피" 검색).
   집 인터넷 IP는 가끔 바뀌니, 나중에 `403` 오류가 나면 다시 등록하세요.
6. **`.env` 채우기** (메모장으로 열기):
   - `TOSS_CLIENT_ID`, `TOSS_CLIENT_SECRET`: 5에서 받은 값
   - `SEC_USER_AGENT`: `pennybot 홍길동 me@example.com` 처럼 이름+이메일 (SEC 공시 조회 규칙)
   - `PENNYBOT_WEBHOOK`: 디스코드 웹훅 주소 (선택, 체결 알림)
   - `PENNYBOT_TELEGRAM_TOKEN`, `PENNYBOT_TELEGRAM_CHAT`: 텔레그램 알림·원격 명령 (선택)
   - `PENNYBOT_DASHBOARD_PASSWORD`: 밖에서 대시보드를 조작하려면 설정 (선택)
7. **계좌·연결 확인**: `pennybot.bat accounts` → 나온 `accountSeq` 숫자를 `.env`의 `TOSS_ACCOUNT`에 → `pennybot.bat check`
   (장 캘린더, 시세, 데이마켓 1분봉이 나오면 정상)
8. **켜기: `start.bat` 더블클릭** → 수집기·매매 봇·대시보드 창 3개가 뜨고 브라우저가 열립니다. 기본은 **모의매매**입니다.
   - 오류로 꺼지면 30초 뒤 자동으로 다시 켜집니다. 창을 닫으면 그 프로그램이 멈춥니다. 기록은 `state\logs`.
   - 같은 프로그램이 이미 켜져 있으면 **새 창이 옛 인스턴스를 인수**하고 새로 시작합니다.
     옛 프로세스를 끝내지 못하면 새 창이 스스로 종료됩니다(중복 실행 방지).
9. **(선택) 휴대폰 알림·원격 제어 — 텔레그램**
   - 텔레그램에서 `@BotFather` → `/newbot` → 받은 토큰을 `.env`의 `PENNYBOT_TELEGRAM_TOKEN`에
   - 내 봇에게 아무 말이나 보낸 뒤 `pennybot.bat telegram-setup` → 나온 숫자를 `PENNYBOT_TELEGRAM_CHAT`에
   - 명령: `/상태` `/정지` `/재개` `/청산 확인` `/리포트 [날짜]` `/종목 PENX` `/대시보드`
10. **(선택) 컴퓨터를 켜면 자동 시작**: `autostart_on.bat` 더블클릭 (해제는 `autostart_off.bat`)

- 컴퓨터가 잠들면 멈춥니다: Windows **설정 > 시스템 > 전원**에서 절전을 "안 함"으로.
  수집기는 24시간, 매매 봇은 한국 오전(데이마켓)부터 다음 날 새벽(정규장)까지 일합니다.
- 새 버전 받기: git 으로 받았으면 `update.bat`. ZIP 이면 새로 받아 풀고 예전 폴더의 `.env`, `config.yaml`, `state` 를 복사 → `setup.bat`.
- 실거래는 모의매매로 충분히 확인한 뒤에만: `config.yaml`의 `mode: live` + `.env`의 `PENNYBOT_LIVE_CONFIRM=YES`.
  대시보드 위쪽 **모드 배지**를 눌러 전환할 수도 있습니다(보유·진행 중 매매가 0건일 때만, 확인 창 있음).

## 데이터 수집 (수집기)

`python -m pennybot collect` 를 24시간 켜 두면 `state/market.db`(SQLite)에 쌓입니다.
모든 행에 `trade_date`(미국 영업일)와 `session`(DAY/PRE/REGULAR/AFTER)이 붙습니다.
데이마켓은 그 영업일 전날 밤(미국 동부 20:00~04:00)이므로 한 영업일은 **데이 → 프리 → 정규 → 애프터** 순서입니다.

| 묶음 | 테이블 | 내용 | 주기 |
| --- | --- | --- | --- |
| 시세 | `universe` | 토스 거래 가능 보통주(NASDAQ·NYSE·AMEX) 중 $0.2~$10 | 하루 1번 |
| 시세 | `prices` | 유니버스 전체 현재가 | 1분 |
| 시세 | `quotes` | 감시 종목 최우선 호가·잔량 (빈 호가도 기록) | 1분 |
| 시세 | `bars_1m` | 감시 종목 1분봉 (세션 꼬리표 포함) | 30분 + 세션 전환 시 |
| 시세 | `rankings` | 시장·토스 거래대금/거래량, 급등·급락 상위 | 10분 (장중 1분) |
| 시세 | `live_tick` | 최근 체결가 (전조·가상매매 갱신용) | 실시간 |
| 공시·뉴스 | `filings` | SEC 공시(Form 4·8-K·6-K·424B·S-1/S-3 등) 접수 시각, 공개 세션, 내부자 매수 금액 | 1분 |
| 공시·뉴스 | `news` | 보도자료 피드(GlobeNewswire·PR Newswire·Business Wire·Accesswire)의 `(NASDAQ: XXXX)` 기사와 호재/악재 판정 | 2분 |
| 공시·뉴스 | `events` | 대시보드·알림에 쓰는 실시간 이벤트 로그 | 발생 시 |
| 공매도·수급 | `short_volume` | FINRA 일별 공매도 거래량·전체 거래량 | 하루 1번 (미국 장 마감 후) |
| 공매도·수급 | `borrow` | IBKR 대차 수수료(연%)·빌릴 수 있는 수량 | 30분 |
| 공매도·수급 | `ssr` / `reg_sho` | Nasdaq SSR(공매도 호가 제한) · Reg SHO 결제불이행 종목 | 하루 1번 |
| 공매도·수급 | `halts` | Nasdaq 거래정지·재개 (LULD 변동성 정지, 뉴스 대기 등) | 1분 |
| 요약·추적 | `session_summary` | 종목·영업일·세션별 OHLCV, VWAP, 스프레드 중앙값 | 애프터마켓 종료 시 |
| 요약·추적 | `runners` | 급등주(+30%)와 희석 점수·펌프 신호 (다음 날 흐름 추적) | 애프터마켓 종료 시 |
| 요약·추적 | `daily_bars` | 일봉. `backfill-daily` 로 과거 2년치를 채움 (셋업·패턴 학습 입력) | 백필 시 |
| 요약·추적 | `stock_info` / `stock_tags` | 발행주식 수·상장일·종목 태그 | 갱신 시 |
| 전조·가상 | `precursor_daily` / `precursor_live` | 과거 +500% 급등 전 증상 점수(일봉)와 장중 신호 | 하루 1번 / 1분 |
| 전조·가상 | `vsignals` | 가상 매매(S1~S6) 신호·체결·청산 기록 | 실시간 |

**자동으로 하는 일**
- 감시 종목 선정(기본 120칸): **수급 50**(최신 랭킹의 거래대금·거래량·회전율 상위) +
  **새 수급 25**(최근 터짐·수급·60분 내 공시·급증 승격) + **순환 45**(최근에 안 본 유니버스 종목).
  등락률은 감시 목록 선정에 쓰지 않습니다.
- 장중에 새로 튀는 종목은 `spike_up`·새 랭킹 진입 시 **30분간 감시 목록에 승격**되어
  호가·1분봉·급등 후보에 바로 나타납니다.
- 유니버스는 하루 1번 갱신하고, 휴장 중(주말 포함)에는 `research` 를 자동으로 다시 돌려 과거 패턴을 최신화합니다.
- 정규장이 끝나고 애프터장이 시작될 때 그날 1분봉을 `research.db` 에 보관합니다.
- 메인 루프가 15분 이상 멈추면 프로세스가 스스로 종료되고 `run_forever.bat` 이 다시 켭니다.

**과거 데이터 채우기**
```bash
python -m pennybot backfill-daily                 # 일봉 (기본 2025-01-01 부터, 중단 후 재개 가능)
python -m pennybot backfill-minutes               # 1분봉 (기본 90일 전 부터, 주말에 데이마켓 구멍 메우기)
python -m pennybot backfill-minutes --pages 50 --limit 100
```

| 알림 | 내용 |

| 급등 전조 | 과거 +500% 급등 전 증상 점수 + 장중 거래 급증·매수세 유입 |

| 바닥 재반등 | 급락 후 저점에서 다시 오르며 거래가 붙는 순간 (2차 파동 초입) |
| 꾸준히 거래 붙음 | 한 번에 터지지 않고 매집처럼 꾸준히 붙는 수급 |
| 뉴스 대기 거래정지 | 거래정지·재개 |
| 프리 개장 주목 목록 | 03:55 ET, 프리마켓에서 움직이는 종목 |
| 장 시작 전 브리핑 | 03:45 ET 요약 |
| 장 마감 성과 요약 | 그날 알림이 실제로 어떻게 됐는지 |
| 재가속 | 급등 뒤 눌렸다가 다시 붙는 순간 |
| 이전 고점 접근·임박 | 최근 급등주가 이전 고점을 넘기 **전에** |
| 가상 매매 | S1~S6 가상 매매의 주문·체결·매도 |

같은 오류 알림은 30분에 한 번만 보냅니다.

## 자동매매 (매매 엔진)

`python -m pennybot trade` (기본 모의매매). 수집기와 같이 돌려야 전략이 후보를 찾습니다.
5초마다 주문 상태를 확인하고, 세션이 바뀌면 걸린 주문을 정리하고, 전략을 스캔해 지정가로 삽니다.

### 전략

전략은 **그룹**과 **개별(소스)** 두 층이 있습니다. 그룹을 켜면 그 안의 소스 전략들이 후보를 내고,
그룹이 목표가·손절가를 통일해 적용합니다.

| 그룹 | 묶는 소스 | 기본 |
| --- | --- | --- |
| `pullback` 눌림 매수 | 플래시 스캘프 · 매집 스텝업 · 데이-프리 가격차 · 매집 포착 · 정규장 모멘텀 · VWAP 눌림 | 꺼짐 |
| `rebound` 역추세 반등 | 역추세 반등 · 데이마켓 급락 반등 | 꺼짐 |
| `surge` 급등 추격 | 뉴스 단타 · 공매도 스퀴즈 · 러너 오버나이트 · 데이 점화 · 희석 촉매 | 꺼짐 |
| `pump` 급등 눌림 | 당일 급등 + 고점 대비 눌림 + 저점 방어 | 꺼짐 |

| 개별 전략 | 무엇을 보고 사나 | 기본 |
| --- | --- | --- |
| `regular_momentum` 정규장 모멘텀 | 정규장 중 새 호재·내부자 매수·수급이 붙으며 +3% 이상 움직인 종목 (최대 8시간 보유) | 켜짐 |
| `scalp` 플래시 스캘프 | 실시간 수급(거래 터짐·애프터 누적·바닥 재반등·+20% 돌파)에 짧게 진입 | 켜짐 |
| `steady_trend` 매집 스텝업 | 꾸준히 붙는 매집 신호. 목표·손절에 안 걸리면 다음 데이마켓 전까지 보유 | 켜짐 |
| `squeeze` 공매도 스퀴즈 | 2일 연속 공매도 비율 40% 이상 + 대차 수수료 30% 이상 + SSR/Reg SHO + 거래대금 $2M 이상 | 켜짐 |
| `news` 뉴스 단타 | 60분 안의 호재 공시·보도자료 + 3분 거래대금 $200K 이상, 신호 후 30% 넘게 안 오른 것 | 켜짐 |
| `session_gap` 데이-프리 가격차 | 데이마켓이 직전 정규장 종가보다 3% 이상 싸고 거래대금 $1M 이상 | 켜짐 |
| `accumulation` 매집 포착 | 20일 박스 상단 5% 이내 + 변동성 수축(ATR10/ATR60 < 0.7) + 거래량 증가 + OBV 상승 | 켜짐 |
| `reversal` 역추세 반등 | 당일 35% 이상 급락 후 저점 대비 15% 회복 + 거래대금 $5M 이상 + 최근 거래정지 없음 | 켜짐 |
| `runner_overnight` 러너 오버나이트 | 전날 +30% 이상, 고가권 마감, 회전 큼, 희석 여력 낮음 → 데이마켓 매수 → 개장 무렵 매도 | 꺼짐 |
| `dilution_catalyst` 희석 촉매 | ATM 종료·증자 등록 철회·공모 철회·자사주 매입 공시 | 꺼짐 |
| `day_ignition` 데이 점화 | 데이마켓에서 새 호재로 막 움직이기 시작 | 꺼짐 |
| `day_dip` 데이마켓 급락 반등 | 급락 반등. 페니주 급락은 증자·펌프 붕괴가 많아 기본 꺼짐 | 꺼짐 |

- `config.yaml` 의 `trading.strategies` 에서 키별로 켜고 끄거나 숫자를 바꿉니다.
- 대시보드 **설정 > 봇 전략** 에서도 실행 중에 켜고 끌 수 있습니다.
- **희석 점수만으로는 더 이상 진입을 막지 않습니다.** 상장폐지·사기성 공시 같은 `차단` 등급과
  펌프 위험 신호 3개 이상만 막고, 점수는 참고용으로 남깁니다.
- 스프레드 상한은 세션별로 다릅니다 (정규 1.5% · 프리 2% · 애프터 3% · 데이 5%).
- 고점 추격·수직 상승 직후 진입은 `chase_guard` 가 거릅니다.

### 매도 순서 (위에서부터 먼저 적용)

1. **강제 청산 시각** — 전략별 마감. 늦어도 미국 정규장 개장(09:00 ET)에 정리
2. **보유 중 악재** — 증자·공모·상장폐지·계속기업 불확실성 등 공시·보도자료
3. **손절** — 전략별 손절가 (모멘텀·스캘프는 -6~8%, 나머지 셋업은 -50% 기준)
4. **트레일링** — `trail_from_high_pct` 를 켠 경우, 일정 수익 뒤 고점 대비 하락
5. **거래량 클라이맥스** — +10% 이상 오른 뒤 1분 거래량이 앞 30분 평균의 5배 이상이면서
   윗꼬리가 봉 범위의 절반 이상일 때만. 거래량만 터지고 고가권에 마감한 상승은 계속 들고 갑니다
6. **반등·매집 없음** — 설정한 시간이 지나도 고점이 안 올라오고, 거래량·거래대금이 실린 하락일 때
7. **익절 / 분할 익절** — 목표가. `scale_out_pct` 가 있으면 일부만 팔고 나머지는 트레일링
8. **변동없음 청산** — 3시간 동안 ±1% 안에서만 움직이면 정리 (데이마켓은 제외)
9. **물량 던지기** — 최근 5분 거래량과 거래대금이 **함께** 터지며 음봉이 3개 이상.
   거래량이 마른 하락은 매집으로 보고 버팁니다
10. **매도 구간 / 장 마감 전 정리** — 전략이 정한 시각, 또는 `flatten_kst`(예: `08:50`) 설정 시 그 한국 시각

### 공통 장치

| 기능 | 내용 |
| --- | --- |
| 매수 | 지정가. 스프레드가 좁으면 ask, 넓으면 중간가 근처. 미체결 시 1회 추격 후 취소 |
| 주문 추적 | 토스는 정정·취소마다 새 주문번호를 주므로 **주문 줄기**로 추적. 새 주문은 멱등키로 중복 방지 |
| 세션 전환 | 세션이 바뀌면 걸린 주문 모두 취소 (토스 DAY 주문이 다음 세션까지 이어지므로) |
| 수량 | 밤사이 최악의 갭 기준으로 손실이 계좌 1%를 넘지 않게. 종목당 계좌 5%·$300 상한 |
| 리스크 | 동시 보유 8, 일일 손실 $150, 최근 7일 손실 $400, 4연속 손실이면 24시간 쉼, 최근 20회 평균 손익 음수면 전략 자동 정지 |
| 서버 손절 안전망 | 보유 중 토스 **조건주문**으로 봇 손절가 3% 아래에 매도를 걸어 둠. **PC·봇이 꺼져도 토스 서버가 손절** |
| 실시간 | 토스 웹소켓으로 보유·후보 호가·체결·내 주문 이벤트. 끊기면 자동으로 REST 폴링 |
| 수수료·한도 | 토스 수수료율을 조회해 순손익에 반영 |
| 매수 유의 차단 | 토스 매수 유의사항(VI 발동·투자경고·정리매매 등)이 걸린 종목은 사지 않음 |
| 장애 대응 | 장 캘린더 실패 시 평일 근사, 재시작 시 열린 주문·멈춘 상태 복구, 잔고 불일치 알림, 매도 거부 반복 시 쉬었다가 재시도 |
| 모의매매 | 실제 토스 호가에 대해 보수적으로 체결 (ask/bid 기준, 최우선 잔량까지만) |
| 일일 리포트 | 영업일이 끝나면 **한국 시간 07:30** 에 알림. `state/reports/` 에 저장, 대시보드·텔레그램에서 다시 보기 |
| 중복 실행 | `collect`·`trade`·`dashboard` 는 한 인스턴스만. 새 창이 옛 인스턴스를 인수 |

## 명령어

윈도우는 `pennybot.bat <명령>`, 맥/리눅스는 `./pennybot.sh <명령>` 입니다.

| 명령 | 하는 일 |
| --- | --- |
| `accounts` | 계좌번호(accountSeq) 확인 → `.env` 의 `TOSS_ACCOUNT` |
| `check` | 연결 점검: 장 캘린더, 시세, 1분봉의 세션 분포 |
| `collect [--once]` | 24시간 데이터 수집 (한 번만: `--once`) |
| `trade [--once]` | 매매 엔진 (기본 모의, 한 번만: `--once`) |
| `dashboard [--demo] [--port 8050]` | 대시보드. `--demo` 는 예시 데이터 |
| `tunnel [--port 8050]` | 대시보드를 외부 주소로 열기 (Cloudflare, 가입 불필요) |
| `telegram-setup` | 텔레그램 chat id 찾기 |
| `summarize --date 2026-10-21` | 그 영업일의 세션 요약 다시 만들기 |
| `audit [--days 30]` | 청산 감사: 매도 사유별 손익, 보유 중 최고가, 청산 후 1시간 가격, 조기 청산 의심 |

| `bigruns [--no-intraday]` | +500% 급등 사례의 급등 전 차트·데이마켓 분석 vs 비교군 |

| `probe-orders --symbol SYM --yes-real-order` | **실제 주문** 1주로 정정·취소 동작 확인 (체결 안 될 가격) |
| `screen` / `run` | (구) Coil & Catalyst 스크리너 / 장중 매매 루프 |

## 리서치·검증

```bash
python -m pennybot audit --days 30
python -m pennybot research --days 180
python -m pennybot bigruns
python -m pennybot chart30
python -m pennybot trigger
python -m pennybot anatomy
```

- `audit`: 닫힌 매매를 매도 사유별로 묶어 **손익 · 보유 중 최고가(MFE) · 청산 후 1시간 가격**을 보여줍니다.
  "너무 일찍 팔았는지 / 너무 늦게 팔았는지"를 숫자로 확인하는 용도입니다. 토스 API 는 부르지 않습니다.
- `research`·`bigruns`·`chart30`·`trigger`·`anatomy`: 토스 일봉·1분봉과 FINRA·SEC 자료를 받아
  `state/research.db` 에 캐시합니다. 처음에는 오래 걸리고, 결과는 대시보드 `#analysis` 화면에 나옵니다.

## 백테스트 (리플레이)

```bash
python -m pennybot backtest                                   # 수집기 DB 전체 기간
python -m pennybot backtest --start 2026-11-02 --end 2026-11-27 --param runner_overnight.trail_pct=6
```

수집기 DB(`state/market.db`)를 1분 간격으로 다시 흘려 **실제 매매 엔진을 그대로** 돌립니다 (토스 API 접속 없음).
- 재생 시각까지의 데이터만 보임: 공시·보도자료·가격 흐름·랭킹·유니버스 모두 as-of 로 잘림 (미래 데이터 차단)
- 체결: 그 시각의 수집 호가 기준. 호가 기록이 없으면 현재가 ±0.75%, 잔량 1,000주로 보수적 가정
- 수수료 0.1% (`--fee`) 반영 순손익, **학습(앞 70%) / 검증(뒤 30%) 구간**을 나눠 과최적화 확인
- 결과는 `state/backtests/<시각>/report.json` + `backtest.db`, 대시보드 `#analysis` 에서 비교
- `--with-edgar`: 희석 프로필까지 (제출일 ≤ 재생일만 써서 미래 공시는 안 섞임, 네트워크 필요)

수집을 시작한 날부터만 데이터가 있으므로, 최소 몇 주 쌓인 뒤에 의미가 있습니다 (거래 30건 미만이면 경고).

**밖에서(휴대폰 등) 보기**: `tunnel.bat` 더블클릭 → `https://….trycloudflare.com` 외부 주소가 열립니다

  주소를 아는 사람은 잔고·매매 기록을 볼 수 있습니다.
- `.env` 에 `PENNYBOT_DASHBOARD_PASSWORD` 를 넣으면: 접속할 때 비밀번호(아이디는 아무거나)를 묻고, 외부에서도 조작할 수 있습니다.

## 문제 해결

| 증상 | 확인 |
| --- | --- |
| `403` | 토스증권 **설정 > Open API > 허용 IP 관리**에 이 PC의 공인 IP 등록 (IP가 바뀌면 다시) |
| `401` | `.env` 의 `TOSS_CLIENT_ID` / `TOSS_CLIENT_SECRET` 확인 |
| 후보가 없음 | 수집기가 같이 돌고 있는지, `state/market.db` 에 데이터가 쌓였는지 확인 |
| 1분봉에 데이마켓이 없음 | `pennybot.bat check` 의 세션 분포 확인. 없으면 `backfill-minutes` |
| "이미 실행 중" | 새 창이 옛 인스턴스를 인수하지 못한 경우. 표시된 `taskkill /F /T /PID <pid>` 실행 |
| 대시보드가 안 열림 | `--port 8060` 처럼 다른 포트로 실행. 이미 켜져 있거나 다른 프로그램이 쓰는 중 |
| 텔레그램이 안 옴 | `telegram-setup` 으로 chat id 확인. 매매 창이 명령을 받는 중이면 409 오류 |

테스트: `.venv\Scripts\python -m pytest -q` (전부 통과해야 합니다)

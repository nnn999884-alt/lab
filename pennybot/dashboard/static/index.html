🚨 급등 전조 = 거래대금·회전율이 평소보다 확 붙고 일봉 등급(★)이 받쳐 줄 때. 📶 거래 터짐 = 거래만 터진 짧은 신호.

결과: 감지가에서 +20% 먼저 갔으면 ✅, −10% 먼저 빠졌으면 ❌ (한 1분봉에서 둘 다 닿으면 ❌로 셈). +30% 찍음 = 그날 전일 종가 대비 +30% 를 찍었나.

과거 확률 = 끝난 거래일의 같은 종류 알림 실제 결과. 건수가 적으면 흔들리니 건수도 같이 볼 것. 평소 = 감시 종목이 아무 날이나 +30% 찍을 확률.

"늦음" = 감지 때 벌써 전일 대비 +20% 넘은 종목. "구 규칙" = 10/23 까지 쓰던 옛 전조 조건 (참고용).
